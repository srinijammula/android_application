# LoyaltyFirst Android Application

## Overview
LoyaltyFirst is an Android-based customer loyalty application developed using Java, Android Studio, JSP, and SQL. It implements a 3-tier architecture to manage customer rewards, transactions, and redemptions efficiently.

## Features
- **User Authentication**: Secure login system using Java Servlets and JDBC.
- **Customer Dashboard**: Displays customer information, collected points, and rewards.
- **Transaction Management**: View transaction history with details of purchases and points earned.
- **Reward Redemption**: Allows customers to redeem points for prizes and view redemption history.
- **Family Points Sharing**: Facilitates point sharing among family members based on transaction points.

## Technology Stack
- **Frontend**: Android Studio (Java) for mobile app UI and activities.
- **Backend**: Apache Tomcat hosting Java Servlets and JSP for server-side business logic.
- **Database**: SQL with JDBC for data storage and retrieval.
